# 📊 HR Analytics Dashboard & Analysis

## 📌 Project Overview
This project analyzes human resources data to uncover key trends in **Employee Attrition**, job satisfaction, and departmental performance. The goal is to provide actionable insights that help HR teams improve employee retention and workforce planning.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel / Power Query:** Data cleaning, transformation, and preprocessing.
* **SQL (MySQL):** Exploratory data analysis (EDA) and extracting key performance metrics.
* **Power BI:** Building interactive dashboards, DAX measures, and visual storytelling.

---

## 📈 Key Insights & Summary
* **Overall Attrition Rate:** **[X]%** of the total workforce left the organization.
* **High-Impact Department:** The **[Department Name, e.g., Sales]** department recorded the highest attrition rate.
* **Compensation & Overtime:** Employees working overtime or earning below the median salary band showed a significantly higher tendency to leave.
* **Tenure Trends:** Attrition peaked among employees with **[1–2 years]** of tenure at the company.

## 🚀 How to Use
1. Download the `.pbix` file from the `HR-Analysis` folder in this repository.
2. Open the file in **Power BI Desktop**.
3. Use the interactive slicers (Department, Gender, Age Group, Job Role) to filter and explore the metrics.
